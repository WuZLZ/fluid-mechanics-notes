# Fluid Atlas · 流体力学课堂速查

> 📘 网页： https://wuzlz.github.io/fluid-mechanics-notes/

一个专门为课堂提问设计的流体力学笔记网页。核心目标：**快速搜索、直接回答、不堆砌无关内容。**

## V3 功能
- 六个课堂章节，自动显示每章知识点数量，新增章节可自动加入目录。
- 全站即时搜索，支持「粘度/黏度」近义匹配。
- 「⚡ 课堂速答」切换：隐藏插图和装饰，优先展示一句话答案。
- 知识卡片：核心回答始终显示，公式和补充默认折叠。
- 专业 SVG 示意图：连续性方程、黏性、静水压、流线和质点运动。
- 轻量动画与减少动态效果支持，适配安卓手机。
- 新增日期、修改日期；最近更新自动排列。
- 可安装网页应用（PWA），支持在成功访问后保存部分离线缓存。

## 更新约定
1. 用户发送课堂讲授内容、PPT或老师的提问，先整理为简洁答案。
2. **只有收到明确「加入」或「更新笔记」指令时，才写入 notes.json。**
3. 与原知识点重复的内容优先合并/修订，不重复堆积。
4. 不主动收入与当前课堂无关的拓展知识。
5. 每条笔记具有唯一 id、chapter、title、answer、detail、formula、keywords、createdAt、updatedAt；旧 content 字段保留兼容。
6. 新建时写入实际日期；修改时更新 updatedAt，但不能覆盖 createdAt。
7. 写入前先读取 notes.json 最新版本 SHA，按 SHA 更新以减少覆盖风险。重要改版保留归档。

## 项目文件
- `index.html`：网页结构与学科主视觉
- `styles.css`：响应式配色、布局与动画
- `app.js`：章节、检索、速答、公式展开与云端 JSON 读取
- `notes.json`：课堂知识点数据，持续追加/修订
- `manifest.webmanifest`：手机添加到主屏幕
- `sw.js`：离线缓存和版本更新策略
- `assets/`：图标素材（插图主要由 SVG 代码绘制）
- `archive/`：重要改版前的数据备份

## 注意
- 此仓库为 Public，网页和笔记内容对公众可见，不要写入私人数据。
- Github Pages 每次提交需要一定构建时间。需要最新知识点时使用网页「刷新」按钮；必要时刷新浏览器。
- 浏览器离线缓存是辅助功能，不应代替 GitHub 历史版本备份。
- 安装到手机桌面取决于浏览器和系统权限，建议 Chrome/Edge 上使用「添加到主屏幕/安装应用」。
